# Migração para Cloudflare Pages

O frontend é estático e usa diretamente um projeto Supabase.

- Repositório: `joaovforex/shopbox-ponto`
- Build command: deixe vazio
- Output directory: `.`
- Branch de produção: `main`

No endereço temporário `*.pages.dev`, valide login, câmera, reconhecimento
facial e gravação do ponto. Confirme que o projeto Supabase pertence à sua
conta antes de desligar a Lovable. Altere o DNS somente após esse teste.
